# ALFA

## 📱 App Android (nessun server, nessun PC)

Scarica **[GPU-Pool.apk](https://github.com/Giuseppe210992/ALFA/releases/download/apk-latest/GPU-Pool.apk)** dal telefono e aprilo.
Se Android lo chiede, consenti l'installazione da questo browser («origini sconosciute»): l'app non è sul Play Store.
Il programma gira **dentro il telefono**; il lavoro pesante parte su Kaggle. Resta una notifica «GPU Pool è attivo» finché l'app è in funzione.

## GPU Pool — modelli AI gratis da una webapp

Il progetto è in [`universal_gpu_pool/`](universal_gpu_pool/README.md).

Avvio: doppio clic su `universal_gpu_pool/avvia.bat` (Windows) o `avvia.command` (macOS), oppure
`python3 universal_gpu_pool/run_webapp.py`. Poi incolla una chiave API gratuita nel pannello «Account e chiavi».
